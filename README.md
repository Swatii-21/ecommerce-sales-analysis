# 🛒 E-Commerce Sales Analysis using SQL

## 📌 Project Overview

This project analyzes e-commerce sales data using SQL to understand customer activity, product performance, and sales trends.

The project uses relational tables for **Customers, Products, and Orders** and applies SQL queries to generate useful business insights.

## 🗄️ Database Structure

The project contains three main tables:

* **Customers** – stores customer details such as name and city.
* **Products** – stores product name, category, and price.
* **Orders** – stores customer orders, product purchases, quantity, and order date.

## 🔍 Analysis Performed

The project answers questions such as:

* How many orders were placed?
* What is the total sales amount?
* Which product categories generate the most sales?
* How many orders did each customer place?
* Which customers spent the most?
* Which customers placed multiple orders?
* How many products are available in each category?
* What is the most expensive product?
* Which products have a price above ₹3000?
* Which products are sold the most?
* How many orders were placed each month?
* How do sales change month-wise?
